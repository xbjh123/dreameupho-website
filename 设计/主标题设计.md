## 1. 参考图标题风格精确分析（看图所得）

对主视觉图中「通向未来的旋律」主标题的逐层拆解（与视觉模型特写分析核对，核心结论一致；装饰音符位置以本次全图观察为准补充说明）：

### 1.1 填充：上白下蓝的垂直渐变

- **方向**：**垂直（正上 → 正下）**。不是水平。顶部受光、底部融入蓝天，字像从天空里长出来。
- **色值**：
  - 顶部起始：**纯白** `#FFFFFF`，约保持字高的上 1/4～1/3；
  - 中段过渡：极浅天蓝（约 `#EAF7FF` → `#8FD9F8` 一带）；
  - 底部结束：**清澈天空蓝**，约 `#34B4E0` ～ `#41BBF5`。
- 过渡平滑均匀，无硬停点。整行字每个字共享同一条垂直渐变（渐变随字形走，不是整行一条色带）。

### 1.2 描边：粗白实色描边

- **颜色**：纯白 `#FFFFFF`，实色、不透明。
- **粗细**：目测 **3～4px**（相对图中约 110px 的字高，约为字高的 3.5%），是「外扩式」描边——渐变填充完整，白边包在字形之外。
- **作用**：这是蓝色文字在蓝天白云背景上清晰可读的核心手段，边缘锐利，勾勒每个笔画的轮廓，带来海报「贴纸字」的挺括感。

### 1.3 发光：青蓝色外发光（一层柔光为主）

- **颜色**：**比背景稍深、饱和度略高的青蓝色**，约 `#208BCA` ～ `#1C90D2`。不是深蓝、不是电气蓝、不偏紫。
- **范围**：向外扩散约 **8～15px**，边缘柔和模糊，典型「外发光」样式。
- **层次**：无明显独立内发光层；白描边与蓝填充的强对比本身构成内部提亮。视觉上可读为「紧贴描边的一层中等光晕 + 更大半径的淡柔光」。

### 1.4 字效层次（从内到外）

1. **填充层**：上白下蓝垂直线性渐变；
2. **描边层**：3～4px 纯白实色描边；
3. **外发光层**：青蓝色柔光，包裹在白描边之外。

### 1.5 装饰元素

- **标题右侧**：一组**白色弧线五线谱飘带**——3～4 条细弧线从左下向右上飘散扬起，末端缀一枚**白色空心音符**。飘带是线条级的、轻盈的，不抢标题主体。
- **顶部小标题区**「吹响吧！上低音号」：黄→白垂直渐变字 + 蓝色描边，左侧一枚亮黄色上低音号图标，文字间夹一枚**亮黄色小 ♪**（约 `#FFD63D`）。黄色音乐符号是这张视觉图里**唯一的暖色点**，非常醒目，带同色微光。

### 1.6 字体气质

- 中等偏粗无衬线黑体，笔画末端方正，有足够分量承载渐变与描边；
- 字距适中偏紧，整体感强；
- 气质：**厚重感与梦幻感并存**——粗笔画带来稳定，蓝白渐变与青色发光融入天空，轻盈、充满希望、面向未来。网站现有字体栈（Noto Sans SC / 思源黑体 900）完全匹配，无需换字。

## 2. 网站主标题设计规范（可直接照抄）

适用对象：`index.html` Hero 区 `<h1 class="hero-title">通向未来的旋律<span class="gold-note">♪</span></h1>`，桌面 56px / 900，移动端 34px。构图（左文右图、左侧渐变遮罩、字号阶梯）沿用 v2/v3 已定成果，**本方案只替换标题的字效层**。

### 2.1 中文主标题「通向未来的旋律」

| 层 | 参数 | 说明 |
|---|---|---|
| 字体/字号 | 现有字体栈，900 字重，桌面 56px / 移动 34px，行高 1.2，字距 0.01em | 不变 |
| **填充** | 线性渐变 **180deg（垂直向下）**，停点：`#FFFFFF 0%` → `#EAF7FF 30%` → `#8FD9F8 62%` → `#34B4E0 100%`，以 background-clip: text 方式随字形填充 | 上 1/3 保持白亮，中段浅天蓝，底部清澈天蓝。四停点平滑，无硬切 |
| **描边** | `-webkit-text-stroke`：**3px `#FFFFFF`**（移动 34px 时用 **2.5px**） | 注意 text-stroke 以轮廓为中心向内外各画一半：3px 实际外扩约 1.5px、内侵 1.5px，视觉白边约 3px——已达参考图「粗白描边」观感的 85% |
| **发光**（filter drop-shadow 三层串联） | ① 紧贴光晕：`0 2px 6px rgba(32,139,202,0.55)`（即 `#208BCA`，青蓝）<br>② 主柔光：`0 0 18px rgba(65,187,245,0.45)`（即 `#41BBF5`，天蓝）<br>③ 氛围远光：`0 4px 32px rgba(30,111,186,0.28)`（全站主蓝，可选但建议保留） | 三层叠加 = 参考图「8–15px 青蓝柔光」的 CSS 等价物。色相全部在青蓝族内，**禁止**再出现 `(0,51,255)` 类电气蓝 |
| 色彩归属说明 | 底部 `#34B4E0` 与发光 `#208BCA`/`#41BBF5` 是全站色板（天晴蓝 `#4A90D9`、薄雾蓝 `#BFE0F7`）向「青空」方向的同族延伸，不引入外族色相，与全站蓝色系统天然协调 | — |

**备选·参考图级厚描边（若项目方对单层描边的「挺括度」仍不满意时启用）**：
双层外扩法——标题元素加 `data-text` 属性复制文字，`::before` 伪元素绝对定位与正文完全重合（同字号/行高/字距），只画 `-webkit-text-stroke: 6px #FFFFFF`、填充透明，置于渐变文字层之下。6px 居中描边 = 真外扩 3px，填充零内侵，100% 还原参考图「渐变完整 + 白边外包」的贴纸感。其余渐变、发光参数不变。此方案需 HTML 增加一个属性，作为升级档备用。

### 2.2 结尾金色 ♪（全屏唯一暖色焦点）

这是参考图「黄色音乐符号」在网站标题上的落点（参考图中黄色 ♪/乐器图标是全图唯一暖色，网站 v1 早已确认「结尾 ♪ 用乐器金」的设计语言，当前实现把它做成了白色，属丢失焦点，必须改回）。

| 项 | 参数 |
|---|---|
| 字符 | `♪`（U+266A），行内末尾，紧跟「律」字 |
| 字号 | `0.62em`（56px 标题下约 35px；移动约 21px） |
| **填充** | 垂直渐变 `180deg`：`#FFE27A 0%` → `#FFD63D 55%` → `#F2B33D 100%`，同样以 background-clip: text 填充。顶部蜂蜜金亮光、中部参考图亮黄、底部落到全站乐器金——一个 ♪ 同时接住参考图与全站色板 |
| 描边 | 无（金色 ♪ 靠光晕立体质感，不描白边，避免与标题字混淆层级） |
| **发光**（text-shadow 三层） | ① 内芯提亮：`0 0 6px rgba(255,226,122,0.9)`<br>② 主光晕：`0 0 16px rgba(255,214,61,0.55)`<br>③ 落地微影：`0 2px 8px rgba(242,179,61,0.35)` |
| 位置 | `margin-left: 0.08em`；`transform: translateY(-0.28em)`（上标式落在「律」字右上方，对应参考图黄色 ♪ 的位置感）；display: inline-block |
| 动效 | **呼吸微光**：光晕透明度 0.85 ↔ 1.0 脉动，周期 4.5s，ease-in-out，无限（克制，是签名时刻的一部分）；hover 时颤音 ±8° 轻摆 0.3s（沿用 v3 动效语言）；`prefers-reduced-motion` 下静止 |

### 2.3 标题下方五线谱飘带（.hero-score 升级）

参考图的飘带在标题右侧且为**上扬弧线**；网站为左对齐构图，飘带置于标题下方、从标题尾部向右扬起，既还原弧线形态又适配网站构图。

- **形态**：内联 SVG，5 条 1px 细线，总宽约 360px、高约 30px；5 条线左端水平起笔（与标题首字左对齐），向右上方轻微扬起（右端整体上抬 12～16px，用二次贝塞尔曲线，中部自然下沉 2～4px 形成「被风吹起」的弧度），线间距 6px。
- **颜色**：`rgba(255,255,255,0.5)`，与现状一致。
- **末端音符**：飘带右上端点处缀一枚 13px 白色空心 `♪`（`rgba(255,255,255,0.75)`），微光 `0 0 8px rgba(255,255,255,0.5)`——对应参考图标题右侧的白色音符。
- **谱上漂浮小音符**：保留现有 2 枚，**全部改为白色系**（`rgba(255,255,255,0.6～0.7)`，13–15px，沿用 floaty 动画）。原那枚黄色小音符改白——标题 ♪ 已是金色焦点，Hero 区内不再出现第二处静态金色（金色配额纪律，见 §2.5）。
- **降级方案**（若不想引入 SVG）：保留现有 CSS 直谱（repeating-linear-gradient），仅做两处修正——线色降为 `rgba(255,255,255,0.45)`、黄音符改白。直谱可接受，但弧线版更还原参考图，优先推荐 SVG。
- **位置**：标题下缘下方 18px（现 14px 微调），与英文副标语间距保持现状 16px。

### 2.4 英文模式（html.lang-en）

- 主标题切换为 `A MELODY TOWARD THE FUTURE`（42px，Quicksand 700，全大写，字距 0.04em——比现 0.01em 略开，英文全大写需要呼吸）。
- **同款字效全套套用**：180deg 垂直渐变（同四停点）、`-webkit-text-stroke: 2.5px #FFFFFF`（42px 字号的比例值）、三层青蓝发光（半径可不变）。
- 结尾金色 ♪ 保留，规格同 §2.2（字号 0.62em 约 26px）。
- 副标语行（heroSub）在英文模式为空隐藏，维持现状逻辑。
- 五线谱飘带不变。
- 注意 42px × 26 个字符的长度：确认不溢出 Hero 文字区 44% 宽度上限；若溢出，英文标题字号降至 38px 而非压缩字距。

### 2.5 移动端与配额纪律

- 移动端（<768px）：标题 34px，描边 2.5px，发光三层半径 ×0.7（约 `0 1px 4px` / `0 0 12px` / `0 3px 22px`），♪ 规格等比。
- **金色配额**：改造后 Hero 屏静态金色 = 标题结尾 ♪ 一处（顶部滚动进度条 ♪ 与导航当前区块 ♪ 属全站固定件，不计入屏内配额）；`hn-4` 那枚 25% 透明度的氛围金音符可保留（不构成视觉焦点）。符合 v1/v3「每屏金色 ≤3–4 处」的克制规则。

## 3. 当前实现与参考图的差距（为什么"不可用"）及改法

| # | 项 | 当前实现（不可用） | 参考图 | 改法 |
|---|---|---|---|---|
| 1 | **渐变方向** | `90deg` 水平，左蓝右白 | **垂直**，上白下蓝 | 改为 `180deg`，按 §2.1 四停点 |
| 2 | **渐变色彩** | `#89D4FF → #FFFFFF`，55% 后全白——整行字大面积死白，无「上白下蓝」层次 | 顶部白 → 底部清澈天蓝 `#34B4E0` 系 | 四停点垂直渐变，底部落到 `#34B4E0` |
| 3 | **描边粗细** | `2px` 白，且 text-stroke 居中绘制实际外扩仅 1px——海报贴纸感不足，字在 CG 上「站不住」 | 3–4px 外扩式粗白边 | 3px（移动 2.5px）；若仍不够挺，启用 §2.1 备选双层 6px 外扩法 |
| 4 | **发光色相** | `rgba(0,51,255)` / `rgba(0,102,255)`——**电气蓝、偏紫**，电竞感，与青空气质冲突（这是"不可用"观感的第一元凶） | 青蓝 `#208BCA` 系，比背景略深，柔和 | 按 §2.1 三层青蓝 drop-shadow 替换 |
| 5 | **结尾 ♪** | 白色半透明 + 白辉光——全屏唯一暖色焦点丢失，与参考图黄色 ♪ 完全不符 | 亮黄 `#FFD63D` + 同色微光 | 按 §2.2 金色 ♪（渐变填充 + 三层金光 + 呼吸微光） |
| 6 | **五线谱飘带** | 标题下方 300px 直线谱 + 一枚黄色小音符（金色焦点分散） | 标题右侧上扬弧线飘带 + 白音符 | 按 §2.3 升级 SVG 弧线飘带，漂浮音符改白，金色收归标题 ♪ |

一句话总结：当前版把「垂直、青蓝、粗白边、金音符」四个核心特征全部做错或做丢，只剩下「字是蓝的」这一点与参考图沾边；按 §2 逐条替换参数即可改到位，不需要动构图、字号与 HTML 结构（仅备选双层描边需加 `data-text` 属性）。

## 4. 验收要点（实现后逐条核对）

1. **渐变方向**：截图放大任意一个字——**顶部像素 ≈ 纯白，底部像素 ≈ 天蓝（`#34B4E0` 族）**，过渡垂直、平滑；整行字不存在「左蓝右白」的水平色差。
2. **描边**：标题压在 hero-bg 的白云区域上时，白描边与云之间仍有青蓝光晕分隔、轮廓可辨；压在蓝天区域时白边清晰挺括，视觉厚度约 3px（56px 字号下），有海报贴纸感。
3. **发光色相**：光晕为青蓝色；从任何角度、任何屏幕上看**没有紫味、没有电气蓝味**（与原 `rgba(0,51,255)` 截图并排对比应一目了然）；可读两层——紧贴字边的中等光晕 + 更大半径的淡柔光。
4. **金色 ♪**：首屏扫一眼，**唯一跳出来的暖色点**就是标题结尾的 ♪；色为亮金（`#FFD63D` 族），带同色微光；位于「律」字右上方上标位。
5. **飘带**：标题下方五线谱呈轻微上扬弧线（或降级直谱），末端白音符可见；谱上无黄色音符。
6. **与参考图并排对比**：将网站首屏截图与主视觉图并列——渐变方向、描边粗细感、发光色相、♪ 的暖色焦点四件事一眼对应。
7. **可读性**：标题在 hero-bg.jpg 全区域（云上/天上/遮罩上）均清晰可读；左半局部遮罩（v2 成果）未被破坏。
8. **英文模式**：`lang-en` 下标题同款渐变/描边/发光生效，不溢出文字区宽度；♪ 保留。
9. **移动端**：34px + 2.5px 描边比例协调，发光不糊成一团；♪ 等比缩小。
10. **动效纪律**：♪ 呼吸微光周期 4.5s 克制不闪；`prefers-reduced-motion: reduce` 下呼吸静止、所有效果静态成立。
11. **金色配额**：Hero 屏静态金色仅标题 ♪ 一处（进度条 ♪、导航当前 ♪ 为全站固定件），无新增金色元素。
