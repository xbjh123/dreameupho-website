### 0.3 「AI 味」判定标准（本轮设计的对照尺）

一个组件被判为 AI 味，通常因为它满足以下任意两条：**任何行业网站都能原样套用**；**hover 只有上浮+阴影加深**；**圆角胶囊/毛玻璃/渐变图标块三件套**；**装饰与项目题材零关联**。本轮每个设计点都必须通过反例测试：「把它原样搬到一个奶茶品牌官网是否依然成立？」——成立即不合格。

## A. 导航栏重设计

### A.1 概念：「节目单谱架」

导航不再是一条"容器"，而是**一张摊开在谱架上的节目单**：底部边缘就是一行五线谱，链接是谱面上的一个个小节，当前区块用一枚金色 ♪ 落在对应小节上标记——与页面顶部的滚动进度 ♪ 形成「演奏进行到哪里」的同一套语言。节目单是纸质印刷品，所以导航是**纯白不透明、无模糊、无投影**的"纸张"。

### A.2 桌面导航精确规范（≥768px）

**整体**

- 高度 72px（原 64px，加高是为了容纳底部五线谱边缘），固定顶部，z-index 100。
- 背景：纯白 `#FFFFFF` 不透明。**删除** backdrop-filter 毛玻璃、删除导航投影。
- 底部边缘：全宽五线谱代替 1px 分隔线——5 条 1px 横线、线间距 4px（总高 17px），颜色 `rgba(30,111,186,0.14)`，紧贴导航下沿。滚动超过 Hero 后谱线加深到 `rgba(30,111,186,0.22)`，作为唯一的"已滚动"反馈。
- 内容容器：max-width 1320px，左右内边距 32px，三段式：左品牌 / 中链接 / 右控件。

**品牌区（左）**

- Logo_b 置于 **40px 正圆形**蓝色底（`--grad-logo` 渐变保留）内，图标 28px。不用圆角方块——圆形是音符符头的形状，圆角方块是 App 图标的形状。
- hover 时圆形外出现 1.5px 乐器金圆环（外扩 3px，0.25s 淡入），无其它位移。
- 右侧两行文字不变：「DreamEupho」Quicksand 700 17px 主蓝 /「梦想悠风」11px 雾灰蓝字距 0.2em。

**链接区（中）——小节化**

- 5 个锚点链接水平排布，每项 padding `10px 18px`，15px 500 雾灰蓝。
- **链接之间用小节线分隔**：1px 宽、20px 高的竖线，`rgba(30,111,186,0.18)`，垂直居中。链接区域整体读起来就是谱面上的 5 个小节。
- **音符槽**：每个链接文字正上方预留一个 14px 高的音符位（占位但默认透明）：
  - hover：一枚 `♪`（13px，天晴蓝，透明度 0.7）在音符位淡入，同时文字变主蓝；
  - 当前区块（滚动监听命中）：音符位常显**乐器金 ♪**（透明度 1），文字主蓝 700。**删除原金色下划线**——下划线是通用 UI 语言，落在小节上的音符才是乐谱语言。
- 音符位与底部五线谱边缘垂直呼应：金 ♪ 像被"写"在这段谱上。

**右侧控件区**

- **语言切换（"移调"文字开关）**：废弃胶囊分段控件。改为纯文字组合：`中 / EN`，13px Quicksand 700；中间分隔符是一根小节线（1px×14px 竖线，蓝 25%），不是斜杠。当前语言：主蓝色 + 文字前一枚 10px 金色 ♪；非当前语言：雾灰蓝，hover 变天晴蓝。选中变化只换颜色与音符，无滑动块动画。
- **「加入我们」**：采用 §C.1 小节线按钮的小号款（高 40px、padding 0 18px、15px）。原纯文字胶囊废弃。
- 控件间距：语言开关与按钮之间 20px。

### A.3 滚动行为与锚点偏移

- 导航始终固定；滚动时**无显隐、无变色**，只有 §A.2 所述谱线加深。固定导航玩"躲猫猫"是模板交互，节目单应当一直摊在谱架上。
- 导航变高（72px）后，全站锚点 `scroll-margin-top` 从 80px 调整为 **88px**。
- 顶部五线谱进度条保留在原位（z-index 300，叠于导航之上），两者共存不冲突：进度条是"演奏进度"，导航是"曲目单"。

### A.4 汉堡按钮（<768px 显示）

- 保留现有的"两条横线 + 金色 ♪"构图（本身已具备定制感），微调：两条横线改为**不等宽**（上 24px、下 16px，右对齐），像一小段被截取的谱线；♪ 保持在下方居中。
- 展开状态：两条线收拢旋转成一根**终止线**（细线+粗线并拢成竖向双线的 45° 旋转太费解，直接用：两线变为竖直并排的"细+粗"终止线，♪ 隐去），表示"合上节目单"。

### A.5 移动端菜单：「演奏会节目单」下拉页

废弃全屏蓝色渐变抽屉（居中大字 + 逐项淡入是 AI 模板标配）。新菜单是一张**从导航下方翻下来的纸质节目单**：

- **形态**：从顶部向下展开的**白色面板**（不是全屏蓝底），高度自适应内容（约 78vh），底部边缘是云朵轮廓曲线（复用 Hero 底部云朵 SVG 路径，白色面板与下方页面之间自然过渡），面板下沿外有 S-卡片悬停级阴影。展开动画：面板 `translateY(-102%) → 0`，0.35s cubic-bezier(0.22,1,0.36,1)，像从谱架上抽出一张纸。
- **页眉**：居中两行——上行 `PROGRAM`（Quicksand 700 11px 乐器金，字距 0.35em），下行「节目单 · 通向未来的旋律」（15px 700 墨蓝）。页眉上方左侧放小尺寸品牌圆标，右上角关闭按钮为**终止线图标**（细 1px + 粗 3px 两条竖线，高 18px，墨蓝），不用 ×。
- **曲目列表**：5 个锚点链接竖排，每行结构为——`01`（Quicksand 700 14px 乐器金）＋ 中文名（22px 700 墨蓝）＋ 点状引线（2px 点、`rgba(30,111,186,0.2)`、flex 撑满）＋ 英文小字（11px Quicksand 雾灰蓝 caps，如 `INTRODUCTION`）。行高 56px，行间 1px `rgba(30,111,186,0.08)` 发丝线。**这就是真实节目单上"曲目……作曲者"的排版**。
- 列表入场：整列随面板一起落下即可，**删除逐条 stagger 淡入上移**（那是模板动效）。
- **底部**：一行内左侧语言开关（同 §A.2 文字款），右侧「加入我们」小节线按钮（主蓝款，高 44px）。面板打开时锁定页面滚动。
- 背景不盖全屏遮罩，页面内容保持可见（面板本身不透明），only 面板下方露出部分加 `rgba(15,61,107,0.25)` 的点击关闭层。

### A.6 为什么这套导航没有 AI 味（交付说明用）

毛玻璃 + 渐变圆角图标 + 胶囊 CTA + 金色下划线是"任何 SaaS 官网"的通解；而**谱线底缘、小节线分隔、落在小节上的金音符、纸感白底、节目单移动菜单**全部从"管乐团演出"这个具体题材里长出来，搬到任何非音乐项目都会水土不服——这就是定制的定义。

## B. 五张横幅的重设计：「总谱页头」

### B.1 设计概念

五个分区页头统一做成**一页管弦乐总谱的标题区**：真实乐谱开头有什么，这里就有什么——**排练编号（方框数字）、速度术语（意大利语）、标题、五线谱、终止线**。预制横幅图不再作为页头主体；其中的吉祥物插画按 §B.3 裁出作为"谱末印章"式小元素。五个页头共享同一骨架，靠**速度术语 + 谱面记号 + 吉祥物**三者变化拉开差异。

### B.2 统一结构框架（自上而下，容器 max-width 960px 居中）

```text
 ┌01┐  ← 排练编号方框（坐在谱线上方左端，如真实乐谱的 rehearsal mark）
 ~~~~~~~~~~~~~~~~ 五线谱（全宽，从容器外两侧穿入） ~~~~~~~~~~~~~~~~ ║▍
        ANDANTE · 行板          ← 速度术语（乐器金小字）          ↑ 终止线
        游戏介绍                 ← 中文大标题                        （谱线右端）
        GAME INTRODUCTION       ← 英文 caps 小字
        引语一句（可选，雾灰蓝）                                     ○ 吉祥物徽章
                                                                   （叠在谱线右端）
```

**精确规格**：

1. **五线谱带**：宽为容器的 116%（左右各溢出 8%），5 条 1px 线、线间距 10px（总高 41px），颜色 `rgba(30,111,186,0.15)`，垂直位置在标题组中线处，从标题组后方穿过。
2. **标题组**：居中偏左（整体左移约 8% 容器宽，避免绝对居中的呆板），自带与区块同色的实底衬（padding `0 28px`）把谱线在文字背后"挖空"，谱线只从文字两侧露出。
3. **排练编号方框**：28×28px、1px 主蓝边框、白底、Quicksand 700 13px 主蓝数字（`01`–`06`），位于谱线左端**上方 8px**（真实乐谱中排练编号就在谱表上方左侧）。编号即乐章号 No.01–06 的载体，`No.` 前缀去掉，方框本身就是编号语言。
4. **速度术语**：乐器金、13px、Quicksand 700、字距 0.25em、caps，如 `ANDANTE · 行板`。这是每页的"演奏指示"，是全页头唯一的金色元素。
5. **中文大标题**：40px / 900 / 墨蓝，行高 1.25。
6. **英文小标题**：12px Quicksand 500 caps、字距 0.3em、雾灰蓝。
7. **引语**：14px 雾灰蓝，与英文小标题间距 12px（仅游戏介绍、招募类区块使用）。
8. **终止线**：谱线右端，细线 1px + 粗线 4px 两根竖线（间距 5px，高 41px 跨满五条谱线），`rgba(30,111,186,0.4)`。
9. **吉祥物徽章**：96px 正圆、白边 4px、S-卡片静置阴影，圆心叠在终止线位置（盖住终止线上半），像乐谱角落的收藏章。徽章内为 §B.3 裁切的吉祥物。
10. 页头整体高度约 220px，下方与正文间距 48px。**删除** v2 的"上下两条 staff-deco 装饰线"和"极淡五线谱纹理底"（新页头自身就是谱面，不再需要底纹），漂移云动画已删（v2）不恢复。

### B.3 吉祥物插画嵌入方案

- **裁切方式**：徽章内直接使用原横幅图（`assets/img/banners/banner-*.jpg`）作为 `<img>`，容器 96px 圆形 overflow hidden，图片 `object-fit: cover` + **逐张手工调整 `object-position` 百分比**使吉祥物脸部居中。吉祥物在原横幅中位于标题艺术字旁侧，初始定位值建议从 `85% 50%`（右侧居中）起调，逐张目测确认后把 5 个定位参数记录在 `data/` 的配置里（与 characters.json 同方式）。
- 等比红线不变：只缩放与容器裁切，不改图本身比例。
- **Fallback（裁切效果差时启用）**：徽章内不放图，改为 `--grad-logo` 蓝渐变底 + 白色 36px ♪。五个页头允许混用（有的区用吉祥物、有的区用音符），视觉上仍然统一。
- **移动端**：徽章缩小为 64px，或整组隐藏（二选一，以实现后目测为准；谱线与终止线保留）。

### B.4 五个分区的差异点（同一骨架上的变化）

| 区块 | 编号 | 速度术语 | 谱面记号（该区独有的装饰） | 含义 |
|---|---|---|---|---|
| 游戏介绍 | 01 | `ANDANTE · 行板` | 谱线左段 3 枚上行 ♪（13px 主蓝 25%，沿谱线逐级抬高 5px/8px/11px） | 游戏开场，如行板起步 |
| 故事背景 | 02 | `ESPRESSIVO · 富有表情地` | 标题正下方一枚**渐强-渐弱 hairpin**（SVG 两条 120px 长线组成 `<>`，1.5px 主蓝 30%） | 故事的起伏张力 |
| 人物介绍 | 03 | `SOLI · 独奏群像` | 谱线上分散 5 枚 ♪（不同垂直位置，模拟不同音高；主蓝 20–30% 深浅不一） | 个性各异的角色们 |
| 制作成员 | 04 | `TUTTI · 全奏` | 谱线右段一簇**和弦**：3 枚符头纵向叠放（间距 10px，像同时奏响的和音） | 全员协作 |
| 重要声明 | 06 | `FERMATA · 延长记号` | 谱线中点上方一枚**延长记号**（SVG：弧线+圆点，宽 28px，主蓝 35%） | 请停下来读一读 |

- 资讯区块（05）无横幅、无吉祥物，文字版页头同步升级：采用相同骨架（编号方框 + 谱线 + 终止线），速度术语 `MODERATO · 中板`，不放置记号装饰。
- 记号实现：♪ 用 Unicode；hairpin、延长记号、和弦符头用内联 SVG（各不超过 6 个元素），不使用任何图片素材。
- 所有记号的透明度都压在 20–35%，是"印谱上的浅蓝油墨"，不是贴纸。

### B.5 移动端适配（<768px）

- 骨架保留：编号方框（24px）+ 标题组居中 + 谱线（线间距 8px，总高 33px）+ 终止线。
- 中文标题 28px/900；速度术语 11px；英文小标题 10px。
- 谱面记号简化：上/下行音符组保留但减到 2 枚；hairpin 宽缩至 88px；延长记号保留。
- 吉祥物徽章按 §B.3 规则缩小或隐藏。
- 页头高度约 160px，下距正文 32px。

### B.6 为什么这不是 AI 味

模板页头是"一张横幅图 + 居中大字 + 副标题"，换张图就是另一个网站。「总谱页头」的每一个零件——**方框排练编号、意大利语速度术语、渐强记号、延长记号、终止线**——都来自真实记谱法，五个区共用骨架却各有演奏指示，且与吉祥物印章形成"乐团节目册"的整体感。这套语言离开了音乐题材就无法成立。

## C. 组件去 AI 化清单

### C.1 按钮 → 「小节线按钮」

**废弃**：胶囊形（radius 999px）+ 实心/描边 + hover 上浮。胶囊是操作系统与 UI Kit 的默认语言，与乐谱无关。

**新造型**：按钮是谱面上的"一小节"——微圆角矩形 + 左侧一组**终止线**（细线 + 粗线的双竖线）。

| 规格 | 值 |
|---|---|
| 形状 | 圆角 **6px**（不再全圆角），高 48px（大号 52px / 小号 40px），padding `0 26px 0 20px` |
| 终止线 | 按钮左内侧 14px 处：1px 线 + 3px 粗线，间距 4px，高 20px，垂直居中 |
| 文字 | 15px / 700 / 字距 0.08em，终止线与文字间距 12px |

**四种变体**：

| 变体 | 静置 | hover | active |
|---|---|---|---|
| 主按钮（浅底） | 主蓝底、白字、终止线白色 75% | 背景转 `#0F3D6B`；**粗线变乐器金并向右滑 2px**（渐强感）；无位移无阴影变化 | 整体 scale(0.98) |
| 白底按钮（深底/Hero） | 白底、主蓝字、终止线主蓝 60% | 粗线变金 + 右滑 2px；字色变天晴蓝 | 同左 |
| 次按钮 | 透明底、1px 主蓝 45% 描边、主蓝字、终止线主蓝 45% | 底色 `#E8F2FC`、粗线变金 | 同左 |
| 文字按钮 | 主蓝 700 + `→` | `→` 右移 4px（保留现状） | — |

**为什么不是 AI 味**：hover 反馈是"粗线镀金并滑动"——一个只在乐谱语境里才有意义的微交互；胶囊上浮在任何模板里都成立，终止线按钮只在乐谱上成立。

### C.2 卡片 → 「乐谱纸卡片」

**废弃**：圆角 16/24px + 蓝调投影 + hover 上浮 4px 阴影加深（当前 `.card` 全套）。这是 AI 落地页辨识度最高的三件套。

**新造型**：卡片是一页从总谱上取下来的**乐谱纸**——纸是平的，靠发丝边框与页眉谱线定义，不靠投影浮起来。

- **静置**：白底、圆角 **12px**、**1px 发丝边框** `rgba(30,111,186,0.14)`、**无投影**；卡片顶部内嵌 40px 高的**页眉谱线带**（5 条 1px 线、间距 6px、主蓝 6%，距顶 12px 起），像乐谱纸的页眉。卡片标题行（如制作成员组名）就排在谱线带区域内。
- **hover（全部不动位置）**：① 边框加深到 `rgba(30,111,186,0.45)`；② 页眉谱线带浓度 6% → 12%；③ 右上角淡入一枚 12px 乐器金 ♪（0→1，0.2s）。**无 translate、无阴影变化**。
- 适用范围：制作成员职能卡、声明三卡、招募页 what-cards、联系卡、岗位乐段卡。岗位卡的左侧 4px 渐变边条**保留**（那是乐段记谱的纵线，已具定制感），但 hover 同样改为边框加深 + 金 ♪，删除上浮。
- Core Team 成员卡：圆形渐变音符头像保留（已是定制件），卡片本体套用乐谱纸规格。

**为什么不是 AI 味**："纸张 + 发丝边框 + 页眉谱线"来自印刷乐谱的物料感；投影悬浮来自 Dribbble 通稿。hover 时"边框显影 + 音符落款"像编辑在谱面上做的批注，而不是"卡片飞起来了"。

### C.3 资讯列表 → 「节目单条目」

**废弃**：白卡 + 左侧日期块 + 左 border 变色 + 阴影上浮（当前 `.news-item` 是标准博客卡片列表）。

**新造型**：节目单上的曲目行——**无卡片**，整列表是一张节目单。

- 结构：窄容器 760px 内，条目为**通栏行**，行与行之间以 1px `rgba(30,111,186,0.1)` 发丝线分隔，行 padding `22px 4px`；列表首行上方加一条同样的线，形成完整表格感。
- 行内布局（桌面）：`08.07`（Quicksand 700 17px 主蓝，格式 DD.MM）＋ 下方 `2026` 小字（10px 雾灰蓝）｜ 标题 17px 700 墨蓝 ＋ 摘要 13px 雾灰蓝 1 行截断 ｜ **点状引线**（2px 点、`rgba(30,111,186,0.2)`、flex 撑满，标题与标签之间的空白由引线填满——节目单"曲目………作曲者"的经典排版）｜ 标签（见 C.5 批注框）｜ `›` 箭头。
- **hover**：整行铺一层 `#E8F2FC` 60% 的底色（从左到右 0.25s 扫入），点状引线变乐器金，标题变主蓝。无位移、无阴影。
- 移动端：日期与标签并入标题上方一行小字，引线隐藏，其余不变。
- 「查看全部」保留文字按钮，置于列表下 40px 居中。

**为什么不是 AI 味**：点状引线是纸质节目单/目录的排印语言，几乎不会出现在 AI 生成的网页里；行式节目单与整站"音乐会"叙事同频，卡片列表与任何博客同频。

### C.4 人物卡微调（保留构图，去通稿交互）

- **主角卡**：16:10 整图 + 底部渐变信息条构图保留（v2 成果）；**删除 hover 卡片上浮**；hover 改为：立绘 scale 1.03（保留）+ 金色短线 32→48px（保留）+ 卡片出现 1px 主蓝 45% 发丝边框（从无到有，0.25s）。信息条底部渐变蓝边保留。
- 信息条顶部再加一条**迷你谱线**（2 条 1px 线、间距 5px、主蓝 20%），让信息条像谱面下方的配器注记栏。
- **配角卡**：同样删上浮，hover = 立绘微亮（保留）+ 发丝边框显影。
- 真由悬念卡：虚线框保留；hover 时虚线边框颜色加深至 60%、`AN UNKNOWN MELODY…` 字距轻微拉开（0.2em→0.28em），营造"信号闪烁"感，比上浮更贴人设。

### C.5 其余零散组件

| 组件 | AI 味现状 | 定制替代 | 一句话理由 |
|---|---|---|---|
| 标签 chip | 胶囊圆角实心/浅底（iOS 风格） | **批注框**：圆角 4px、1px 主蓝 30% 边框、透明底、12px 700 主蓝；招募类标签为金框金字（无金底） | 实心胶囊是系统组件语言；描边小方框是乐谱页边的批注章 |
| 页脚分隔线 | 1px 直 `<hr>` | **五线谱分隔**：5 条 1px 线、间距 5px、白色 12% | 页脚是乐曲尾声，分隔线也应是谱线 |
| 页脚社交链接 | hover 下划线 | hover 时链接前淡入 10px 蜂蜜金 ♪，不下划线 | 与前文"音符标记当前项"同一套语言 |
| 语言切换 | 胶囊分段控件（iOS segmented control） | §A.2 文字 + 小节线分隔 + 金色 ♪ 标记当前语言 | 分段控件是 OS 组件；文字开关是排版语言 |
| 汉堡 → 关闭 | × 字符 | 终止线图标（细+粗双竖线） | 终止线 = 乐谱的"结束"，语义比 × 更贴题 |
| 提示条（招募页 tip-bar） | 左 3px 色条 + 浅底（Notion 风） | 左侧改**谱号位**：竖向双竖线（小节线）+ 行前 14px ♩ | 色条提示框是笔记软件语言 |
| ENCORE 页头 | 结构保留 | 标题上方加 `ENCORE` 的排练编号方框（写 `EN`），与首页编号体系一致 | 编号方框成为全站统一的"乐章身份证" |

### C.6 动效体系：从"通用漂浮"到"记谱动作"

**废弃**：① 一切 hover 上浮（translateY -2/-4px）；② 阴影随 hover 加深；③ 通用 fade-up（上移 24px + 淡入）作为唯一进入动效；④ 移动菜单逐条 stagger 淡入。

**新动效语言**（全部 transform/opacity，保持轻量）：

| 场景 | 动效 | 参数 |
|---|---|---|
| 区块进入 | **谱线先行**：页头五线谱带 `scaleX 0→1`（变换原点左端，像划线一样写出）→ 随后标题组淡入 | 谱线 0.7s ease-out；标题延迟 0.15s、0.5s；内容区 opacity + 仅 8px 微升 |
| 卡片进入 | **纸张落定**：opacity 0→1 + `rotate(1.2deg)→0`（微倾斜回正，像一页纸被放上谱架） | 0.5s ease-out，同组卡片交错 60ms |
| hover（全局原则） | 只变色、变线、显音符，**零位移** | 0.2–0.25s |
| 音符 hover | **颤音 vibrato**：±8° 快速轻摆 2 次 | 0.3s，仅用于按钮/链接上的 ♪ |
| 移动菜单 | 节目单面板从顶部落下（§A.5） | 0.35s cubic-bezier(0.22,1,0.36,1) |
| 保留不动 | Hero 漂浮音符 + 云朵视差（签名时刻）、滚动进度金 ♪、下滑提示 | 维持 v2 |
| 降级 | `prefers-reduced-motion: reduce`：全部动画关闭，内容直出 | 维持现状实现 |

**为什么不是 AI 味**：AI 模板动效的核心是"东西会浮起来"；这套动效的核心是"谱线被写出、纸页被放上谱架、音符打颤音"——每个动作都有音乐语义，且全站 hover 零位移反而比模板更克制、更"印刷品"。

## D. 实施注意（给工程师的交接要点）

1. **改动顺序建议**：C.1 按钮 → C.2 卡片 → A 导航（含移动菜单）→ B 页头（5+1 个）→ C.3 资讯 → C.4/C.5 零散 → C.6 动效。按钮与卡片是全局类，先换能立刻统一观感。
2. **导航变更牵连**：高度 64→72px，`scroll-margin-top` 全站改 88px；Hero 内不需要为导航预留额外空间（Hero 内容垂直居中，72px 覆盖无碍）。
3. **删除清单**：`.nav` 的 backdrop-filter/box-shadow、`.card/.char-card/.news-item/.job-card` 的 hover translate 与 shadow 过渡、`.fade-up` 的 24px 位移、`.mv` 组件（被编号方框取代，资讯页头同）、`.lang-switch` 胶囊样式、staff-deco 双装饰线与 head-visual 底纹。
4. **五线谱工具类复用**：现有 `.staff`（repeating-linear-gradient）继续作为谱线实现基础，页头/导航/页脚/卡片页眉共用，只改线距与颜色参数。
5. **吉祥物裁切**：5 个 object-position 参数需逐张目测后写入配置；若某张裁不出好构图，启用 §B.3 的音符徽章 fallback，不硬凑。
6. **金色配额复核**：改造后每屏金色出现点 = 页头速度术语 1 处 + 导航当前 ♪ 1 处 + 进度条 ♪ 1 处（+ 徽章 fallback 若启用），仍 ≤3–4 处，符合 v1 克制规则。卡片 hover 才出现的金 ♪ 不计入静态配额。
7. **验收快测**：把导航截图发给不知情的人问"这是什么网站"——答出"和音乐/乐团有关"即通过；把按钮卡片截图问"像不像模板"——答不像即通过。
