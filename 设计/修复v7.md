## A. 移除 CG 上的白色线条（透明态导航去谱线）

- 透明态（Hero 上）：`.nav` 的 `::after` 五线谱**删除**（白色 0.16 谱线不再显示）——Hero CG 完全干净
- 纸感态（滚动后 `.nav.paper`）：谱线保留（主蓝 0.12/0.22，那是"节目单"在纸上的谱线，用户无异议）
- 实现：把 `::after` 谱线规则从 `.nav`（默认）移到仅 `.nav.paper` 下；透明态 nav 无 `::after` 内容
- recruit 页 ENCORE 页头同样检查（若顶部透明导航共用此规则则一并生效）

## B. 导航 Logo 去重（留左删右）

## C. 修复滚动卡手（按 Vercel 动效准则）

### C.1 移除 scroll-snap（卡手主因）
- 删除 `html { scroll-snap-type: y proximity }` 与 `section[id] { scroll-snap-align: start }`
- 恢复自由平滑滚动（`scroll-behavior: smooth` 仅用于锚点跳转，保留）

### C.2 动效收敛为「一次性的轻量乐章表演」（保留一节一节的感觉，去掉卡顿）
- 保留每区块进入的一次性表演（baton 起拍 → 谱线写出 → 编号 pop → 标题淡入 → 内容落定），但：
  - **总时长压缩到 ≤0.9s**（原约 1.6s 太长，滚动中频繁触发易卡）
  - 表演**只触发一次**（IO 触发后 `unobserve`，语言切换重渲染时直接显示不重演）——现有 `mvIO` 已是单次，确认 `observeFadeUp` 不重复触发
  - 严格**只用 transform/opacity**（Vercel 准则）；检查现有 `.baton`、`.score-staff`、`.mv-*` 是否含 margin/width 动画，若有改为 transform
- 正文内容区：入场改为 opacity + 8px 微升（保留），交错 ≤40ms

### C.3 消除滚动时的布局抖动
- **nav `.paper` 切换**：确认滚动监听是 passive + requestAnimationFrame 节流（无 `getBoundingClientRect`/`scrollTop` 布局读）；阈值判断用 `scrollY`，不触发强制同步布局
- **检查 `transition: all`**：全局搜索替换为显式属性列表（Vercel 准则禁止 transition: all）
- 检查是否有元素在滚动中高频改类导致 reflow（如 `.baton` 每次进入都重排）——baton 是绝对定位 transform 动画，无布局影响，保持
- 漂浮音符/云视差的 scroll 监听同样 rAF 节流 + 只改 transform

### C.4 可打断性（Vercel 准则）
- 进入动画进行中用户继续滚动时，动画不阻塞滚动（transform/opacity 天然不阻塞）；确认无 JS 侧 lock/等待
- 语言切换等重渲染不重放已触发区块动画（直接显示）
